Fleet Flow

Project Overview

Fleet Flow is a truck allocation and delivery management system designed for a truck-selling company. It helps the company track available trucks, allocate trucks to customers, and monitor deliveries to ensure they arrive on time.

Objectives

- Track trucks available in existing stock.
- Track trucks that need to be sourced or imported.
- Allocate trucks to customers.
- Manage deliveries handled by company drivers and external transporters.
- Monitor delivery progress and expected delivery dates.
- Identify delayed deliveries.

Key Features

- Truck Management: Record truck details and availability.
- Customer Allocation: Assign trucks to customers.
- Delivery Tracking: Monitor delivery status and expected arrival dates.
- Transport Management: Track company drivers and external transporters.
- Status Updates: Identify pending, in-transit, delivered, and delayed trucks.
